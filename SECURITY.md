# Security Policy

## Supported versions

Grove is pre-1.0 and moves quickly. Security fixes are only supported
against the latest commit on `main` until a versioned release process
exists.

## Reporting a vulnerability

Please report security vulnerabilities privately via
[GitHub Security Advisories](https://github.com/grove-dav/grove/security/advisories/new)
rather than a public issue.

You should expect an initial response within a few days. Once a fix is
ready, we'll coordinate disclosure timing with you.
